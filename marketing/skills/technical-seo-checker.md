## How this skill applies the marketing laws

- A slow, broken or unfindable website is a physical availability problem: it stops buyers who already want you.

## Current best practice

- Use current Core Web Vitals (LCP, INP, CLS).
- Check that AI crawlers and search engines can read key pages.

## For a small business

- Plain-language fixes the owner or their web builder can do, in order of impact.
