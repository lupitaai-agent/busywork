# Copywriting

Fast conversion copy: headlines, CTAs, and page structures built from proven
formulas. This skill is the short path. When the deliverable is a complete article, guide, or
landing page, use **content-writer** instead; it carries the full workflow, the CORE-EEAT
checklist, and the author attribution block.

---

## Step 0: Load Brand Context

If `the Brand Profile` exists, read it before asking questions.
Also read the Brand Profile. Apply the voice hard rules to every line of copy:
no em dashes, no contractions, no banned words, lead with the finding.

Positioning order: capability and orchestration first, then expertise, then cost efficiency.
Price is supporting evidence, never the lead. Never name or criticise competitors in any copy
that will be published.

---

## Step 1: Confirm the Task

| Task | What to deliver |
|------|-----------------|
| Headline | 3 to 5 options built from the formulas in `references/copy-frameworks.md`, each labelled with its formula |
| CTA | 2 to 3 options: [Action Verb] + [What They Get] + [Qualifier if needed] |
| Hero section | Headline + subheadline + primary CTA, with a one-line rationale each |
| Page outline | A structure template from `references/copy-frameworks.md` matched to the page goal |
| Copy critique | Line-by-line notes against the copywriting principles below |

---

## Step 2: Apply the Principles

| Principle | Rule |
|-----------|------|
| Clarity over cleverness | If clear vs. creative, choose clear |
| Benefits over features | Features say what it does. Benefits say what that means for the reader |
| Specificity over vagueness | "48-hour provisioning" beats "fast setup" |
| Customer language | Mirror voice-of-customer phrasing from the Brand Profile |
| Active voice | "the business publishes the audit in minutes," never "the audit can be published" |
| No exclamation points | Confidence does not need exclamation marks |

---

## Step 3: Build From the References

- `references/copy-frameworks.md`: headline formulas (outcome, problem, audience,
  differentiation, and proof focused), landing page section types, page structure templates,
  and section writing tips.
- `references/natural-transitions.md`: transition phrasing that keeps copy readable and
  passes the Yoast transition threshold, plus the list of AI-tell transitions to avoid.

Every example delivered to the user must itself pass `scripts/voice-check.py`.

---

## Step 4: Deliver

Present options with a one-line rationale each. State which formula produced each headline so
the user can judge the mechanism, and mark one option as the recommendation.
